## 教室電腦第一次使用
1. 用瀏覽器打開主畫面，按右下角 ⚙︎ → 輸入**教室密碼** → 開啟教室模式。孩子就能點燈號、抽扭蛋。
2. 要進後台時，登入畫面**不要勾**「記住我」，關掉分頁就會自動登出。

## 主畫面小工具（右下角 ⚙︎ 左邊）
- ⏱ **計時器**：點一下叫出圓形計時器，再點一下收起來。
  - 用手指拖到畫面任何地方；拉圓圈右下角的把手可以放大縮小。位置和大小會記在這台電腦。
  - 點圓圈打開設定：倒數／順時、快速時間、自訂時間、±1 分鐘、時間到響鈴。下面的粉紅按鈕直接開始／暫停。
- 🐻 **安靜熊**：按「開始聽教室的聲音」，瀏覽器問麥克風時按「允許」。太吵熊熊會被吵醒。
  - 「多吵會吵醒熊熊」和「麥克風靈敏度」可以依教室調整，設定會記在這台電腦。
  - 白板沒有麥克風的話，插一支 USB 麥克風就能用。
- 程式在 `js/class-tools.js`、樣式在 `css/class-tools.css`，只放在主畫面。

## 修改網站後，怎麼更新到公開網址
1. 跟 Claude 說要改什麼，Claude 改好後先執行 `python3 tools/bump_version.py`（更新版本號，讓瀏覽器抓新檔案），再存檔（commit）。
2. 打開 **GitHub Desktop**，按上方的 **Push origin**。
3. 等 1～2 分鐘，公開網址就更新了。如果看到的還是舊畫面，按 `⌘ + Shift + R` 重新整理。

## 換電腦或電腦壞掉時，怎麼把檔案拿回來
1. 在新電腦安裝 **GitHub Desktop**（https://desktop.github.com ），用同一個 GitHub 帳號登入。
2. 選 **File → Clone repository**，選這個專案，存到桌面。
3. 用 Claude Code 打開那個資料夾，就能繼續修改。

> 資料（作業、燈號、獎品、紀錄）都存在 Supabase 雲端，換電腦不會不見。

## 雲端資料庫（Supabase）
- 網址：https://supabase.com （用 GitHub 帳號登入）
- `supabase/` 資料夾裡的 SQL 檔，依編號在 **SQL Editor** 執行過一次即可：
  1. `01_第一階段_資料表.sql`：作業燈號
  2. `02_設定老師與教室帳號.sql`：帳號身分
  3. `03_扭蛋機.sql`：扭蛋機
  4. `04_聯絡簿.sql`：聯絡簿連結
  5. `05_倒數日.sql`：倒數日
  6. `06_題庫.sql`：全班對戰的題庫（題組＋題目圖片空間）
  7. `07_自動封存與清除.sql`：全班完成自動封存、後台「清除一學期前的封存」
  8. `08_成績紀錄.sql`：全班對戰的成績紀錄（後台「📊 成績紀錄」）
- 登入帳號：
  - 老師 `teacher@shiny11.local`
  - 教室 `classroom@shiny11.local`
  - 忘記密碼時，到 Supabase「Authentication → Users」重設。
- 免費方案連續 7 天沒人用會暫停。GitHub 每 3 天會自動連一次，避免暫停（`.github/workflows/keep-supabase-awake.yml`）。
  - 萬一還是暫停了，到 Supabase 專案頁按 **Restore** 即可，資料不會不見。

## 安全說明
- `js/config.js` 裡的是 Supabase「公開鑰匙」，本來就可以放在網頁裡。真正的保護靠資料庫權限：
  - 沒登入：只能看燈號。
  - 教室模式：只能改綠燈、抽扭蛋。
  - 老師：全部功能。
- **secret / service_role 鑰匙、老師與教室密碼，絕對不要寫進任何檔案。**
- 網頁上只顯示座號，不放孩子姓名。

## 全班對戰（分數大冒險連線版）
- 白板打開「全班對戰」頁，會出現 QR code 和四位數房間代碼。孩子用 iPad 相機掃 QR code（代碼會自動填好），輸入暱稱、點自己的座號就能加入（座號不會顯示在白板或 iPad 上，只有後台看得到）；也可以自己打開 `live.html` 輸入代碼。
- 同一個座號只能有一個人；有人選錯或重複加入時，老師在白板大廳點那個名字就能移出房間。
- 用 Supabase 的「即時廣播」連線。
- 成績紀錄：每場比賽結束，白板會把「座號、暱稱、隊伍、答對、答錯、分數、名次」和每題全班答對率存到資料庫（不存姓名）。
  - 白板電腦要先開「教室模式」（或老師登入）才存得進去。白板是投影給孩子看的，所以只在大廳左邊和結算畫面右下角顯示小小的「💾 ✓」（已存／會存）或「💾 ✕」（沒存，旁邊的 ↻ 可以再存一次），滑鼠移上去才看得到說明。
  - 老師後台 →「📊 成績紀錄」：「👧 每個孩子」看每個座號的場數、答對率、搶答平均名次；「🎮 每一場」看每場細節。可以匯出 Excel（.csv）、刪除單場、清除半年前的成績。
  - 測試模式（`?test=1`）不會存成績；要測試儲存再加 `&save=1`。
- 白板左邊會顯示「✅ iPad 連線路徑正常」；如果顯示 ⚠️，一樣能玩，只是人多時可能較慢。
- 想在同一台電腦先試玩：兩個網址後面都加上 `?test=1`（白板開一個分頁、iPad 頁開幾個分頁）。
- 🪢🔮 拔河和賽跑的防亂按（設定在 `js/live-common.js` 的 `LIVE`）：
  - 題目先出現，選項 1.5 秒後才能按（`OPTION_DELAY_MS`）。
  - 答錯要「🧘 冷靜一下」：第 1 次 3 秒、連錯第 2 次 5 秒、第 3 次以上 8 秒，等待時看得到正確答案（`WRONG_LOCKS`）。
  - 連續答對 3 題以上，每題算 2 倍力氣，iPad 顯示「🔥 連對」（`COMBO_AT`、`COMBO_POWER`）。
  - 白板也會再檢查一次，太快或冷靜時間內送來的答案不算。
- 🔮 玻璃球賽跑：先專心答題（白板只看得到全班答對總數，看不出哪隊領先），時間到或老師按「🏁 現在開始賽跑」後，3、2、1、GO！玻璃球在彎彎曲曲的賽道上比賽。途中會互相超車，但最後名次照「每隊平均每人答對幾題」。賽跑秒數在 `js/live-marble.js` 最上面的 `RACE`。
- 🎵 背景音樂（只在白板播，iPad 不出聲）：答題時是緊張的小曲，最後幾秒會加快；玻璃球賽跑是快樂的賽馬曲。音樂是程式即時合成的原創小曲，沒有版權問題。白板右上角 🎵 可以開關音樂、🔊 開關全部聲音。
  - 目前賽跑音樂是老師提供的「Cutscene Crush」（Blue Deer Studio），放在 `music/race.mp3`。
  - 想換成自己的音樂：把 mp3 放進 `music/` 資料夾，在 `js/live-music.js` 最上面的 `FILES` 填檔名（例如 `'music/think.mp3'`）。請用可以合法在課堂使用的免版稅音樂。
- 秒數、題數等設定在 `js/live-common.js` 最上面的 `LIVE` 區塊。
- 自己出題：老師後台 →「🎮 題庫」新增題組（可一題一題打、從試算表整批貼上、加圖片）。白板大廳的「題目」選單就能選；三種玩法都能用。
  - 整批貼上的欄位順序：題目｜選項A｜選項B｜選項C｜選項D｜正確答案（A～D、1～4 或正確選項文字）。
  - 也可以用 Excel：編輯題組 →「📋 整批貼上」→「📥 下載 Excel 範本」，填好後按「📂 從檔案匯入」（支援 .xlsx 和 .csv）。範本在 `templates/quiz-template.xlsx`，要改範本請改 `tools/make_quiz_template.py` 再執行。
  - 題組有勾「把 3/4 顯示成上下排版的分數」時，題目和選項裡的 3/4、?/12 會自動變成上下排版。

## 主畫面：全班完成動畫
- 某項作業從「還有人沒完成」變成「全班綠燈」時：球球變成彩色記憶球慶祝 → 架子由下往上一層一層傾斜、球球滾出去 → 櫃子收掉。
- 「點錯了，復原」的 10 秒過了以後，教室電腦會自動把這項作業移到後台「已封存的作業」（需要先執行 `07_自動封存與清除.sql`）。按錯可以在後台按「還原」。
- 後台「已封存的作業」最下面有「🧹 清除一學期前的封存」，只會刪掉封存超過 6 個月的作業。
- 作業數量決定排版：3 項以下每層 6 顆、4 層；4 項以上每排 4 個櫃子，每層 4 顆、6 層，超過 4 項會往下排。
